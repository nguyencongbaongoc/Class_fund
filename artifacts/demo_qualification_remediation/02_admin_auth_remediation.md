# Admin Authentication Remediation

## Issue
Admin Dashboard authentication simulation returned 401 instead of expected 200/403 for OWNER_TREASURER and MODERATOR roles.

## Root Cause
The test fixtures in `tests/conftest.py` were using mock tokens in format `Bearer mock-token-{user_id}` instead of proper JWT tokens generated by `create_access_token()`. The FastAPI `OAuth2PasswordBearer` dependency expects valid JWT tokens signed with the configured secret.

## Fix Applied
Modified `tests/conftest.py` auth helper functions to use real JWT tokens:

```python
from app.core.security import create_access_token

def get_auth_headers(user_id: str, role: str = "MEMBER") -> dict:
    """Get authorization headers for a user with proper JWT token."""
    token = create_access_token(subject=user_id, role=role)
    return {"Authorization": f"Bearer {token}"}

def get_owner_headers() -> dict:
    return get_auth_headers("owner-1", "OWNER_TREASURER")

def get_moderator_headers() -> dict:
    return get_auth_headers("moderator-1", "MODERATOR")

def get_member_headers() -> dict:
    return get_auth_headers("member-1", "MEMBER")

def get_public_headers() -> dict:
    return get_auth_headers("public-1", "PUBLIC")
```
